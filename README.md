<!----------------- 
    Design Choices
 ------------------->
 The general design concept is to give users a "game-like" feeling when using this web app. 
 As such, the color choice was intentional:
   Lime Green #76FF00 to communicate a sense of energetic and vibrant vibe.

   Pale Green #E5FFC4 is a softer color compare to lime green. It evokes a sense 
   of calmness and at the same time makes a fresh clean look as a background or headings color.

   Charcoal Black #1E1E1E was used to give the website a modern and sleek look. It helps to create contrast on the website.

   The fonts used (Montserrat and Roboto) were chosen bacause they are both easy to read modern san-serif fonts.

   The layout of text on the website follows a visual hierarchy structure, which makes the content breathable and easy to read.

   I want users to feel as if they are actually using a pokedex, hence the reason I chose to have a pokeball appear immediately when the user catch a pokemon. 

   The battle arena helps to make the website more dynamic and gives user a space to be competitive.
